# SAMCORE TECHNOLOGIES 💻🇬🇭

> A modern, high-contrast monochrome online storefront for certified laptops, creator workstations, and enterprise computing hardware across Ghana.

## Overview
- **Location & Model**: 100% online platform with campus delivery & UENR desk in Ghana.
- **Design System**: Strict monochrome (`#000000` / `#FFFFFF`), clean typography, zero clutter.
- **Ordering**: Direct WhatsApp ordering (`050 946 1505` / `055 755 5192`) with auto-generated spec sheets and Ghana Cedi (`GH₵`) pricing.
- **Roles**:
  - Customer Storefront (`/`, `/shop`, `/categories`, `/laptop-finder`, `/track-order`, `/account`)
  - Staff Operations Portal (`/staff`)
  - Admin Inventory & Restocking Workbench (`/admin`)

## Features
- **Stock Transparency**: Verified in-stock indicators, partner allocations, and out-of-stock badges.
- **Specs Configurator**: Customers can customize RAM, SSD, and delivery region before ordering.
- **Announcement Flyer**: High-resolution campus notice popup on first visit with quick-order buttons.
- **Product Management**: Admin upload for new gadget photos and spec configurations.
- **Lucide Icons**: Replaced all raw emojis with clean Lucide React icon components.

## Tech Stack
- **Framework**: Next.js (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React

## Getting Started

1. Clone repository:
```bash
git clone <your-repo-url>
cd "SAMCORE TECHNOLOGIES"
```

2. Install dependencies:
```bash
npm install
```

3. Run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
